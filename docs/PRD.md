# 产品设计文档：爱快 DHCP 网关切换助手（aikuaidhcp）

> 版本：v0.1（MVP 草案）
> 状态：待评审
> 更新日期：2026-09-11

## 1. 产品概述

**一句话定位**：一款自用的 Android 应用，让用户用手机一键切换爱快（iKuai）路由器内网中指定终端的 DHCP 网关地址。

**要解决的问题**：

- 内网某台终端需要在两个网关之间切换（如主网关 / 备用网关、普通上网网关 / 特殊上网网关）。
- 每次切换都要登录爱快 Web 后台，层层点击进入 DHCP 静态分配设置，操作繁琐、易出错。
- 移动端快速操作的诉求无法满足。

## 2. 目标用户与使用场景

- **目标用户**：个人自用（技术型用户，拥有爱快路由器管理权限）。
- **使用场景**：
  - 在家 / 办公室，想给某台设备（如机顶盒、NAS、测试机）临时换一个网关。
  - 掏出手机，几秒内完成切换，无需打开电脑。

## 3. 整体方向

- **形态**：Android 原生 APK（Flutter 跨平台实现，便于未来扩展 iOS）。
- **定位**：轻量单机工具，非多用户、非云同步产品。
- **核心思路**：把"改某台终端的网关"简化为"两个预设网关之间的 A/B 开关"，最大限度降低操作成本。
- **MVP 原则**：只做能形成闭环的最少功能，够用即可。

## 4. 核心功能（MVP 范围）

### 4.1 路由器连接与配置

- 输入爱快地址（IP:端口）、用户名、密码。
- 本地保存连接信息，下次打开免输入。
- 连接状态提示（成功 / 失败）。

### 4.2 终端列表

- 从爱快拉取 DHCP 静态分配 / 在线终端列表。
- 每台终端展示：设备名、IP 地址、MAC 地址、当前网关。
- 支持手动刷新。

### 4.3 网关 A/B 切换（核心功能）

- 每台终端对应一个 A/B 二选一开关。
- 点击开关即在「网关 A ↔ 网关 B」之间切换。
- 切换后实时提交到爱快（按 MAC 定位终端，建立 / 更新 DHCP 静态绑定并指定网关）。
- 显示切换结果（成功 / 失败）。

### 4.4 设置

- 预设「网关 A」和「网关 B」两个地址。
- 可修改路由器连接信息。
- 可清除已保存的登录凭据。

## 5. 功能闭环

```
连接路由器 → 查看终端列表 → 一键切换网关 → 即时生效
```

## 6. 非 MVP（后续规划，暂不实现）

- 批量切换多台终端。
- 自定义任意网关（自由输入，而非仅 A/B）。
- 定时 / 计划任务切换。
- 多台路由器管理。
- 终端分组与收藏。

## 7. 技术方案概述

| 模块 | 方案 |
|------|------|
| 客户端 | Flutter（Android APK） |
| 后端 | 无自有后端，直接调用爱快本地 HTTP API |
| 认证 | 爱快登录接口（MD5 密码 + Base64 salt，多 salt 自动尝试） |
| 会话 | sess_key cookie 会话管理，过期自动重登 |
| 数据持久化 | 本地存储连接信息与网关预设（shared_preferences） |
| 网络 | HTTP / HTTPS，忽略自签名证书 |

## 8. 关键交互流程

1. 首次打开 → 进入连接页 → 输入路由器信息 → 连接成功。
2. 进入终端列表 → 看到所有终端及当前网关。
3. 点某台终端的 A/B 开关 → 直接切换 → 提示成功。
4. 设置页修改网关 A/B 地址 → 返回列表即时生效。
