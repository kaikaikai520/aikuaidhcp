# 产品设计文档：爱快 DHCP 网关切换助手（aikuaidhcp）

> 版本：v0.2（Web 服务形态）
> 状态：待评审
> 更新日期：2026-09-22

## 1. 产品概述

**一句话定位**：一款部署在内网的轻量 Web 服务，浏览器输入一个地址即可查看爱快（iKuai）路由器内网终端的 DHCP 静态分配，并对每台终端在预设的两个网关之间一键切换。

**要解决的问题**：

- 内网某台终端需要在两个网关之间切换（如主网关 / 旁路由网关、普通上网 / 特殊上网）。
- 每次切换都要登录爱快 Web 后台，层层点击进入 DHCP 静态分配设置，操作繁琐、易出错。
- 希望在手机、电脑等任意设备上，无需安装 App，打开网页即可快速操作。

## 2. 目标用户与使用场景

- **目标用户**：个人自用（技术型用户，拥有爱快路由器管理权限）。
- **使用场景**：
  - 在家 / 办公室，想给某台设备（如机顶盒、NAS、测试机）临时换一个网关。
  - 用手机或电脑浏览器打开 `http://内网IP:8000`，几秒内完成切换。

## 3. 整体方向

- **形态**：内网 Web 服务（浏览器 + 后端），后端常驻于一台内网设备（NAS / 软路由 / 台式机等）。
- **定位**：轻量单机工具，非多用户、非云同步产品。
- **核心思路**：把「改某台终端的网关」简化为「两个预设网关之间的 A/B 开关」，最大限度降低操作成本。
- **MVP 原则**：只做能形成闭环的最少功能，够用即可。

## 4. 核心功能（MVP 范围）

### 4.1 路由器连接与配置

- 输入爱快地址（IP:端口）、用户名、密码，可选 HTTPS。
- 配置持久化到服务端 `config.json`，重启自动加载。
- 连接状态提示（成功 / 失败）。

### 4.2 终端列表

- 从爱快拉取 DHCP 静态分配列表。
- 每台终端展示：设备名、IP 地址、MAC 地址、当前网关。
- 支持手动刷新。

### 4.3 网关 A/B 切换（核心功能）

- 每台终端对应一个 A/B 开关（关 = 网关 A，开 = 网关 B）。
- 点击开关即在「网关 A ↔ 网关 B」之间切换。
- 切换后实时提交到爱快（按 MAC 定位终端，更新 DHCP 静态绑定的网关字段）。
- 显示切换结果（成功 / 失败）。

### 4.4 设置

- 预设「网关 A」和「网关 B」两个地址。
- 可修改路由器连接信息。

## 5. 功能闭环

```
访问网页 → 连接路由器 → 查看终端列表 → 一键切换网关 → 即时生效
```

## 6. 非 MVP（后续规划，暂不实现）

- 批量切换多台终端。
- 自定义任意网关（自由输入，而非仅 A/B）。
- 定时 / 计划任务切换。
- 多台路由器管理。
- 终端分组与收藏。
- Web 访问鉴权（内网自用，默认不加密码）。

## 7. 技术方案概述

| 模块 | 方案 |
|------|------|
| 后端 | Python + FastAPI（单服务，REST API + 静态托管） |
| 前端 | 单页 HTML + 原生 JS（无构建步骤，移动端响应式） |
| 爱快调用 | 后端 `requests` 直连爱快本地 HTTP API |
| 认证 | 爱快登录接口（MD5 密码 + Base64 salt，多 salt 自动尝试） |
| 会话 | sess_key cookie 会话管理，过期自动重登 |
| 数据持久化 | 后端落盘 `config.json`（连接信息 + 网关预设） |
| 部署 | Docker 容器（NAS/软路由/Linux 常开设备） |

## 8. 关键交互流程

1. 首次打开 → 进入配置页 → 填写路由器信息 + 网关 A/B → 保存并连接。
2. 连接成功 → 进入终端列表 → 看到所有终端及当前网关。
3. 点某台终端的 A/B 开关 → 直接切换 → 提示成功并刷新。
4. 顶栏「设置」修改连接信息或网关 A/B → 保存后返回列表。
